# Web3 AI 講座 課題 (lecture3)

## 1. レポ概要
このリポジトリは、Web3 AI講座の第3回講義の宿題を提出するためのものです。
AIを活用して抽出したバグリストと、その解決策（VPC）を管理しています。

## 2. Antigravity プロンプト
今回の課題作成にあたり、Antigravityに対して以下のプロンプトを使用しました。

1. 「今回、宿題で画像の１と２をやる。まず１をやる。自分で考えた以下の20個のバグリストをbug-list.mdに書いてください。（20個のリストを添付）」
2. 「『11：カラオケで歌う曲が～』を選定したい。vpc-v1.mdに以下の例のように書いて（VPCの構成案と例を提示）」
